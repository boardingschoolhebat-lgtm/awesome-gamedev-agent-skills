# Pacing, monsters and scares

Depth for `horror-game`: tension curve, rule sheets, budgets and tests.

## Tension curve (30-minute slice)

```text
0-5    calm exploration, establish rules
5-8    unease: sounds, distant glimpse
8-12   first encounter, escape, learn counterplay
12-15  recovery, resource check
15-22  pursuit with a new rule
22-25  safe zone, story beat
25-30  climax encounter
```

- Mark intensity 0–5 per beat; avoid more than two 5s in a row.
- Every high needs a low after it.

## Monster rule sheet

```text
Name:
Senses:        sight / sound / smell / light
Trigger:       what starts a chase
Chase speed:   relative to player walk/run
Lose condition: how it loses the player
Search:        duration and spots checked
Counterplay:   hide / distract / block / fight / wait
Kill:          instant / grab / damage
Tells:         audio + visual before attack
```

## Resource budget (per hour)

| Resource | Target |
|----------|--------|
| Health kits | 2–4 |
| Ammo | 10–20 shots |
| Light/battery | 15–25 min |
| Safe rooms | 2–3 |

- Place refills before difficulty spikes, not after.
- Guarantee one path forward that needs no combat.

## Scare types

| Type | Use |
|------|-----|
| Anticipation | most of the runtime |
| Reveal | first monster sighting |
| Chase | systemic threat |
| Jumpscare | rare punctuation |
| Environmental | world changes when revisited |
| Psychological | unreliable info, sound |

## Test checklist

1. Player can explain the monster's rules after one encounter.
2. Every chase has an escape route or timer.
3. Resource scarcity never softlocks.
4. Tension alternates with release.
5. Scares are telegraphed enough to be fair.
6. Hiding is risky, not a safe button.
7. Checkpoints precede encounters.
8. Photosensitivity and motion options work.
9. Audio cues have visual counterparts.
10. Playtesters describe tension, not boredom or anger.
