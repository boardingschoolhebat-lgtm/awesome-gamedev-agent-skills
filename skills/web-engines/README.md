# Web engine skills

Thirteen Agent Skills for browser games: Phaser 4.2 core, Arcade Physics, tilemaps, UI,
animation and audio; PixiJS 8.22 rendering, UI and animation; and three.js r187 scene, glTF,
material, lighting, and UI workflows (HTML overlays, CSS2D/CSS3D labels, raycasted 3D buttons).

Each subdirectory is one skill. Existing projects keep their locked dependency
versions; see [`VERSION-SUPPORT.md`](../../docs/VERSION-SUPPORT.md).

See [`docs/SKILL-FORMAT.md`](../../docs/SKILL-FORMAT.md) for the authoring standard.
